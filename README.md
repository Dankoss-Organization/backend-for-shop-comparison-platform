# Backend — Shop Comparison Platform

This repository contains the backend services for the Shop Comparison Platform: API, background workers, and database schema.

Full developer and API documentation is published as web docs in the `docs/` folder.

- Documentation index: [docs/index.html](docs/index.html)
- API docs: [docs/api/index.html](docs/api/index.html)

Quick start

```bash
# install deps
npm install

# run locally (dev)
npm run start:dev

# or using Docker
docker compose up --build
```

For detailed guides (testing, logging, architecture, search, multithreading, database, and full API reference) see the web documentation linked above.
