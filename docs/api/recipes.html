Recipes

Recipe catalog endpoints for listing, details, categories, and related recipes.

GET /api/v1/recipes

Returns paginated recipe cards with search, category, difficulty, and sorting filters.

GET /api/v1/recipes?page=1&limit=20&search=pasta&difficulty=easy&sort=rating
{
  "items": [
    {
      "id": "rec-1",
      "name": "Creamy Pasta",
      "imageUrl": "https://images.example.com/recipe.jpg",
      "difficulty": "easy",
      "prepTime": 25,
      "servings": 2,
      "categoryId": "cat-pasta",
      "avgRating": 4.8,
      "reviewCount": 18
    }
  ],
  "total": 1,
  "page": 1,
  "limit": 20,
  "totalPages": 1
}

GET /api/v1/recipes/categories

Returns the recipe category tree, or a subtree when parentId is provided.

GET /api/v1/recipes/categories?parentId=cat-desserts
{
  "categories": [
    {
      "id": "cat-desserts",
      "name": "Desserts",
      "parentId": null,
      "recipeCount": 12,
      "children": []
    }
  ]
}

GET /api/v1/recipes/:id/related

Returns related recipes based on category and difficulty.

GET /api/v1/recipes/rec-1/related?limit=8
{
  "recipeId": "rec-1",
  "related": [
    {
      "id": "rec-2",
      "name": "Garlic Pasta",
      "difficulty": "easy",
      "prepTime": 20
    }
  ]
}

GET /api/v1/recipes/:id

Returns a single recipe with ingredients, equipment, reviews, and aggregate rating data.

GET /api/v1/recipes/rec-1
{
  "id": "rec-1",
  "name": "Creamy Pasta",
  "imageUrl": "https://images.example.com/recipe.jpg",
  "instructions": "Boil pasta, prepare sauce, combine and serve.",
  "difficulty": "easy",
  "prepTime": 25,
  "servings": 2,
  "category": { "id": "cat-pasta", "name": "Pasta" },
  "avgRating": 4.8,
  "reviewCount": 18
}
