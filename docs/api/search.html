Search

Meilisearch-backed search endpoints, health checks, task tracking, and index statistics. Query examples below follow the current DTOs and response shapes.

GET /api/v1/search

Full-text search over the product catalog with optional filter and sort parameters.

GET /api/v1/search?q=apple+iphone&limit=20&offset=0&filter=category+%3D+%22Electronics%22&sort=bestPrice:asc
{
  "results": [
    {
      "id": "prod-123",
      "canonicalName": "Apple iPhone 15",
      "brand": "Apple",
      "category": "Electronics",
      "bestPrice": 45999,
      "storeNames": ["Foxtrot", "Eldorado"]
    }
  ],
  "totalHits": 150,
  "query": "apple iphone",
  "processingTimeMs": 42,
  "count": 20,
  "offset": 0,
  "limit": 20,
  "totalPages": 8,
  "page": 1
}

GET /api/v1/search/advanced

Advanced search with structured filters, sorting, facets, and price statistics.

GET /api/v1/search/advanced?q=iphone+15&page=1&limit=20&filters.categoryId=cat-001&filters.brand=Apple&filters.minPrice=5000&sort.field=bestPrice&sort.direction=asc&facets=category,brand,storeNames
{
  "results": [],
  "totalHits": 150,
  "facets": [
    {
      "name": "brand",
      "values": [
        { "value": "Apple", "count": 12 }
      ]
    }
  ],
  "priceStats": {
    "min": 1000,
    "max": 100000,
    "avg": 45000
  },
  "appliedFilters": {
    "category": "Electronics",
    "minPrice": 5000,
    "maxPrice": 50000
  }
}

GET /api/v1/search/suggestions

Autocomplete endpoint that returns the most relevant product names for a query prefix.

GET /api/v1/search/suggestions?q=iph&limit=10
{
  "suggestions": ["Apple iPhone 15", "Apple iPhone 15 Pro"],
  "query": "iph"
}

GET /api/v1/search/health

Health check for the Meilisearch instance.

{
  "status": "healthy",
  "message": "Meilisearch is running",
  "version": "1.10.2",
  "timestamp": 1716030000000
}

GET /api/v1/search/stats

Returns current index statistics, including document count and last update time.

{
  "numberOfDocuments": 10000,
  "isIndexing": false,
  "lastUpdate": 1716030000000,
  "timestamp": 1716030000000
}

GET /api/v1/search/task/:taskId

Returns the status of an asynchronous Meilisearch task. The task ID is a path parameter.

GET /api/v1/search/task/1
{
  "taskUid": 1,
  "indexUid": "products",
  "status": "succeeded",
  "type": "documentAdditionOrUpdate",
  "enqueuedAt": "2026-05-18T10:00:00Z",
  "startedAt": "2026-05-18T10:00:01Z",
  "finishedAt": "2026-05-18T10:00:02Z",
  "duration": 1000
}
