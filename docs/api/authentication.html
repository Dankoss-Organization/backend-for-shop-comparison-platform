Authentication

Bearer-token verification, current user lookup, and session logout. The controller is mounted at /auth, not /api/v1/auth.

Endpoints

POST /auth/verify

Verifies a bearer token, creates a session, and returns the authenticated user.

{
  "Authorization": "Bearer eyJhbGciOiJIUzI1NiIs..."
}
{
  "user": {
    "id": "usr_123",
    "email": "alice@example.com"
  }
}

GET /auth/me

Returns the current authenticated user from the active JWT session.

{
  "user": {
    "id": "usr_123",
    "email": "alice@example.com"
  }
}

POST /auth/logout

Revokes the current token session. Successful responses return HTTP 204 and no body.

{
  "Authorization": "Bearer eyJhbGciOiJIUzI1NiIs..."
}
