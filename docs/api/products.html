Products

Product catalog, detail, offer, sync, and related-product endpoints. Examples below use the actual response shapes returned by the product service.

GET /api/v1/products

Lists catalog items with pagination and filters for brand, category, price, stock, and search.

GET /api/v1/products?page=1&limit=20&search=barilla&inStock=true&sort=updated
{
  "items": [
    {
      "id": "prod-1",
      "canonicalName": "Spaghetti Barilla No.5 500g",
      "brand": "Barilla",
      "categoryId": "cat-pasta",
      "media": "https://images.example.com/barilla.jpg",
      "offers": [
        {
          "id": "off-1",
          "storeId": "s_silpo",
          "price": 45.99,
          "regularPrice": 59.99,
          "discountPercent": 23
        }
      ],
      "bestPrice": 45.99,
      "bestDiscount": 23,
      "updatedAt": "2026-05-27T10:00:00.000Z"
    }
  ],
  "total": 1,
  "page": 1,
  "limit": 20,
  "totalPages": 1
}

GET /api/v1/products/categories

Returns the product category tree, or a subtree when parentId is provided.

GET /api/v1/products/categories?parentId=cat-food
{
  "categories": [
    {
      "id": "cat-food",
      "name": "Food",
      "slug": "food",
      "children": []
    }
  ]
}

GET /api/v1/products/:id/card

Returns the product card with top offers, pricing summary, badges, and history stats.

GET /api/v1/products/BAR-005/card
{
  "product": {
    "id": "prod-1",
    "productId": "BAR-005",
    "canonicalName": "Spaghetti Barilla No.5 500g",
    "brand": "Barilla",
    "category": "Pasta",
    "media": "https://images.example.com/barilla.jpg",
    "description": "Classic durum wheat spaghetti"
  },
  "pricingSummary": {
    "bestPrice": 45.99,
    "oldPrice": 59.99,
    "discountPercent": 23,
    "currency": "UAH"
  },
  "availabilityStatus": "in_stock"
}

GET /api/v1/products/:id/offers

Returns all offers for a product, sorted by price, discount, or update time.

GET /api/v1/products/BAR-005/offers?sort=price&inStock=true
{
  "productId": "prod-1",
  "offers": [
    {
      "id": "off-1",
      "store": { "id": "s_silpo", "brand": "Silpo", "city": "Kyiv" },
      "currentPrice": 45.99,
      "discountPrice": null
    }
  ],
  "total": 1
}

GET /api/v1/products/:id/price-history

Returns the price history for the requested time period. The default period is 30d.

GET /api/v1/products/BAR-005/price-history?period=30d
{
  "productId": "prod-1",
  "period": "30d",
  "points": [],
  "stats": {
    "minPrice": 42.5,
    "maxPrice": 59.99,
    "avgPrice": 48.6,
    "trend": "down"
  }
}

GET /api/v1/products/:id/related

Returns similar products based on category and brand overlap.

GET /api/v1/products/BAR-005/related?limit=8
{
  "productId": "prod-1",
  "related": [
    {
      "id": "prod-2",
      "canonicalName": "Spaghetti Barilla No.3 500g",
      "bestPrice": 41.99
    }
  ]
}

POST /api/v1/products/:id/sync

Queues a background sync job for the product. The request body can include an optional source.

{
  "source": "manual-refresh"
}
{
  "queue": "product-sync",
  "jobName": "product-sync",
  "jobId": "123",
  "status": "queued",
  "createdAt": "2026-05-27T10:00:00.000Z"
}

GET /api/v1/products/sync-jobs/:jobId

Returns the current status for a queued product sync job.

GET /api/v1/products/sync-jobs/123
{
  "queue": "product-sync",
  "jobId": "123",
  "name": "product-sync",
  "status": "processing",
  "attemptsMade": 0,
  "data": { "productId": "BAR-005", "source": "manual-refresh" },
  "result": null,
  "failedReason": null
}

POST /api/v1/products/:id/analytics/rebuild

Queues an analytics rebuild job for the selected product and period.

{
  "source": "manual-analytics",
  "period": "30d"
}
{
  "queue": "product-analytics",
  "jobName": "product-analytics",
  "jobId": "456",
  "status": "queued",
  "createdAt": "2026-05-27T10:00:00.000Z"
}

GET /api/v1/products/analytics-jobs/:jobId

Returns the current status for a queued analytics rebuild job.

GET /api/v1/products/analytics-jobs/456
{
  "queue": "product-analytics",
  "jobId": "456",
  "name": "product-analytics",
  "status": "completed",
  "attemptsMade": 0,
  "data": { "productId": "BAR-005", "period": "30d", "source": "manual-analytics" },
  "result": { "productId": "prod-1", "offersCount": 8, "bestPrice": 45.99 },
  "failedReason": null
}
