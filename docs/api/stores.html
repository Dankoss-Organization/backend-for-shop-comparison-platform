Stores

Store brand listing and store-scoped product browsing endpoints.

GET /api/v1/stores

Returns the available store brands and their location counts.

{
  "stores": [
    {
      "id": "s_silpo",
      "brand": "Silpo",
      "logo": "https://assets.dankoss.ua/logos/silpo.png",
      "website": "https://silpo.ua",
      "locationCount": 42
    }
  ]
}

GET /api/v1/stores/:storeId/products

Returns products sold in a specific store with the same filtering model as the product catalog.

GET /api/v1/stores/s_silpo/products?page=1&limit=20&search=barilla&sort=price_asc
