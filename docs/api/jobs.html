Jobs / Queue

Background job status endpoints for product sync and analytics jobs. The current backend does not expose a public /api/v1/queues endpoint.

GET /api/v1/products/sync-jobs/:jobId

Checks the status of a previously enqueued product sync job.

GET /api/v1/products/sync-jobs/123
{
  "queue": "product-sync",
  "jobId": "123",
  "name": "product-sync",
  "status": "completed",
  "attemptsMade": 0,
  "data": { "productId": "BAR-005", "source": "manual-refresh" },
  "result": { "productId": "prod-1", "offersCount": 8, "bestPrice": 45.99 },
  "failedReason": null
}

GET /api/v1/products/analytics-jobs/:jobId

Checks the status of a product analytics rebuild job.

GET /api/v1/products/analytics-jobs/456
{
  "queue": "product-analytics",
  "jobId": "456",
  "name": "product-analytics",
  "status": "queued",
  "attemptsMade": 0,
  "data": { "productId": "BAR-005", "period": "30d", "source": "manual-analytics" },
  "result": null,
  "failedReason": null
}
