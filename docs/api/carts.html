Carts

Authenticated cart endpoints for reading and mutating the active cart.

GET /api/v1/cart

Returns the active cart with aggregated product and offer data.

{
  "id": "cart_usr_9921",
  "isActive": true,
  "items": [
    {
      "id": "ci_item_001",
      "quantity": 2,
      "price": 45.99,
      "offer": {
        "id": "off_shopp_771",
        "currentPrice": 45.99,
        "discountPrice": null,
        "product": {
          "productId": "BAR-005",
          "canonicalName": "Spaghetti Barilla No.5 500g",
          "media": "https://images.example.com/barilla.jpg"
        },
        "store": {
          "id": "s_silpo",
          "brand": "Silpo",
          "city": "Kyiv"
        }
      }
    }
  ],
  "sum": 91.98,
  "discountSum": 0,
  "currency": "UAH"
}

POST /api/v1/cart/items

Adds a cart item or increases its quantity when the offer already exists.

{
  "offerId": "off_shopp_771",
  "quantity": 2
}
{
  "success": true,
  "cartItemId": "ci_item_001"
}

PATCH /api/v1/cart/items/:itemId

Updates a cart item quantity.

PATCH /api/v1/cart/items/ci_item_001
{
  "quantity": 3
}
{
  "success": true,
  "cartItemId": "ci_item_001"
}

DELETE /api/v1/cart/items/:itemId

Deletes a cart item from the active cart.

DELETE /api/v1/cart/items/ci_item_001
{
  "success": true,
  "cartItemId": "ci_item_001"
}
