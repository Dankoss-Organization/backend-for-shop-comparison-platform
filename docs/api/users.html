Users

Authenticated user favorites endpoints.

GET /api/v1/users/me/favorites

Returns the current user's favorite product IDs.

{
  "productIds": ["BAR-005", "KMO-112", "GAL-025"]
}

POST /api/v1/users/me/favorites/:productId

Adds a product to the current user's favorites.

POST /api/v1/users/me/favorites/BAR-005
{
  "success": true,
  "productId": "BAR-005"
}

DELETE /api/v1/users/me/favorites/:productId

Removes a product from the current user's favorites.

DELETE /api/v1/users/me/favorites/BAR-005
{
  "success": true,
  "productId": "BAR-005"
}
