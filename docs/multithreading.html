Мультипоточність та Воркери

Модель конкурентності, поведінка фонівих процесів і рекомендації з налаштування фонових задач.

Область покриття

  • Розмежування API та воркерів
  • Потоки: `ENABLE_WORKER_THREADS`
  • Налаштування черг та паралельність
  • Поради та усунення несправностей

Ключові налаштування (приклад)

WORKER_CONCURRENCY=4
ENABLE_WORKER_THREADS=true
ANALYTICS_WORKER_CONCURRENCY=2
UV_THREADPOOL_SIZE=8

Детальніше про поведінку воркерів та модель конкурентності дивіться у [docs/multithreading.md](multithreading.md).
